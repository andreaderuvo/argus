Why Argus

Stop babysitting terminals.

Agents run for minutes, then stop to ask something — and you find out forty minutes later, over ssh, squinting at a pane. Argus fixes the three things that waste your day.

Know when an agent needs you

Every session says working or waiting for you — worked out from the pane itself, with nothing to install in the agent. Add a one-line hook and it rings you, too — even in another tab.

See what it produced, instantly

Every path an agent prints is a link. The report, the plot, the PDF open right beside the session that made them — rendered, not downloaded.

Keep going from your phone

The same sessions, still running, on your phone — with a real keyboard bar for Ctrl, Esc and arrows. Answer from the train; close the tab; it carries on.

How it works

Three steps. Nothing to change in how you work.

Argus attaches to the tmux sessions you already have. It does not wrap your agent, and closing the browser never stops anything.

Install it on the machine

A URL with a private token, or a QR code for your phone. No account, no cloud relay.

Yours, and only yours

Get started

Running in a minute.

Linux and macOS; Windows through WSL or Docker. It prints a link — open it, or scan its QR code with your phone.

# read it first, then run it
curl -fsSLO https://raw.githubusercontent.com/andreaderuvo/argus/master/install.sh
less install.sh && bash install.sh
argus --allow-write            # prints a URL with a token in it
git clone https://github.com/andreaderuvo/argus && cd argus
ARGUS_UID=$(id -u) ARGUS_GID=$(id -g) docker compose up -d
# images for amd64 and arm64: ghcr.io/andreaderuvo/argus
git clone https://github.com/andreaderuvo/argus && cd argus
pip install -r requirements.txt
python3 -m app.main            # prints a URL with a token in it

Questions

Before you try it.

Do I have to change how I use tmux?

No. Argus attaches as one more client to the sessions you already have. What you see in the browser is the same pane you would see over ssh, and closing the tab leaves everything running.

Does it need a plugin in my agent?

No. It reads what the session prints and types into it, like you do. Working and waiting are worked out from the pane. An optional one-line hook lets an agent ring you on its own.

Is it safe to reach from outside?

It is shell access behind a token, so treat it that way: a LAN, a VPN or Tailscale are the sensible shapes — Tailscale also gives you a certificate for free.

How is this different from a web terminal?

A web terminal gives you the terminal. Argus is for the other half of the job: the files the agent writes, the report it produced, the paths it printed, knowing when it needs you — and the phone.

Several machines?

Run Argus on each; Panoptes is one page over all of them, a tile per machine.

What is it built with?

Python on the server, plain JavaScript in the browser. No build step, no database, MIT licensed.
