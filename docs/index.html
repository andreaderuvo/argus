0:argus* open source · self-hosted · MIT

A hundred eyes on your AI agents.

A web workspace for the coding agents you already run in tmux. See which one is working and which is waiting for you, open what it wrote in one click, and answer from your phone.

Install Argus See the code
$ curl -fsSLO https://raw.githubusercontent.com/andreaderuvo/argus/master/install.sh && bash install.sh

Works with Claude Code, Codex, Gemini CLI, Aider, OpenCode, and anything else that runs in a terminal.

1:why*

Agents work for minutes. Then they stop and wait for you.

You find out forty minutes later, over ssh, squinting at a pane. Argus takes care of the part of the job that is not typing: knowing, seeing, answering.

  • Know when one needs you

    Every session says working or waiting for you, worked out from the pane itself. There is nothing to install in the agent.

  • See what it produced

    Every path an agent prints is a link. The report, the plot and the PDF open beside the session that made them, already rendered.

  • Answer from anywhere

    The same sessions, still running, on your phone, with a key bar for Ctrl, Esc and the arrows. Close the tab and the work carries on.

2:how*

It attaches to the sessions you already have.

Argus is one more client of your tmux server. It does not wrap your agent or move your work, and closing the browser never stops anything.

  1. Install it where your agents runA workstation, a server, a box in a cloud. One script, Docker, or pip.
  2. Open the link it printsIt carries a private token, and there is a QR code for the phone. No account.
  3. Your sessions are already thereEvery tmux session, with its files and reports. You can start new agents from the page too, with their first instruction typed in.
3:hand-offs*

Pass work from one agent to the next.

Keep your prompts in a library, with placeholders filled in for each project. Drag one onto a session and it is typed there. The Enter is left for you, so the last word is yours.

  • Desks, not tabs

    Terminals, folders and documents side by side, one desk per project, kept between visits.

  • Start an agent from the page

    A shell or an agent from your own list, in a folder, with its first instruction and, if you want, in a fresh git worktree.

  • Two agents on one job

    A worker and a reviewer, talking through a file you can read.

4:phone*

Your desk, in your pocket.

It is the session that was already running, not a copy of it. You get a key bar for the keys a phone has not got, a long press to open a path, and a box to write a line in when the keyboard fights the terminal.

6:yours*

It runs on your machine, and nothing leaves it.

No cloud

No relay, no account, no telemetry. Code, sessions and files stay where they are.

A token per device

Every request carries a private token. Revoke a phone without touching the others.

A jail for files

Only the folders you name can be read, and writing is off unless you turn it on.

It works best behind a LAN, a VPN or Tailscale. How it is kept safe

7:install*

Running in a minute.

Linux and macOS, or Windows through WSL or Docker. It needs Python 3.11 or newer and tmux, and it prints a link: open it, or scan its QR code with your phone.

# read it first, then run it
curl -fsSLO https://raw.githubusercontent.com/andreaderuvo/argus/master/install.sh
less install.sh && bash install.sh
argus --allow-write          # prints a URL with a token in it
git clone https://github.com/andreaderuvo/argus && cd argus
ARGUS_UID=$(id -u) ARGUS_GID=$(id -g) docker compose up -d
# images for amd64 and arm64: ghcr.io/andreaderuvo/argus
git clone https://github.com/andreaderuvo/argus && cd argus
pip install -r requirements.txt
python3 -m app.main          # prints a URL with a token in it

8:faq*

Before you try it.

Do I have to change how I use tmux?

No. Argus attaches as one more client to the sessions you already have. What you see in the browser is the same pane you would see over ssh, and closing the tab leaves everything running.

Does it need a plugin in my agent?

No. It reads what the session prints and types into it, the way you do, and it works out working and waiting from the pane. An optional one-line hook lets an agent ring you on its own.

Is it safe to reach from outside?

It gives shell access behind a token, so treat it that way: keep it on a LAN, a VPN or Tailscale. Tailscale also gives you a certificate for free.

How is this different from a web terminal?

A web terminal gives you the terminal. Argus covers the rest of the job: the files the agent writes, the report it produced, the paths it printed, knowing when it needs you, and the phone.

What is it built with?

Python on the server and plain JavaScript in the browser. There is no build step and no database. MIT licensed.

Stop checking on your agents. Let them tell you.
